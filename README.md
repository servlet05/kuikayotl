# 🎵 Kuikayotl

Kuikayotl es un proyecto que muestra música latinoamericana alojada en Internet Archive, con una interfaz similar al Jamendo clásico de 2006.

## ✨ Características

- 🌎 20 países latinoamericanos con banderas
- 🎵 Música real desde Internet Archive
- 🖼️ Portadas de álbumes
- 🔊 Reproductor de audio funcional
- 📊 Estadísticas en tiempo real
- 📱 Diseño responsive (móvil, tablet, escritorio)
- 🎨 Estilo inspirado en Jamendo 2006
