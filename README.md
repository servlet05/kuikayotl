# 🎵 Kuikayotl

Kuikayotl es un sitio web que muestra álbumes musicales de México alojados en Internet Archive, con una interfaz similar al Jamendo clásico de 2006.

## ✨ Características

- 📀 Muestra álbumes musicales desde Internet Archive
- 🖼️ Portadas de álbumes usando `__ia_thumb.jpg`
- 🔊 Reproductor de audio funcional (MP3, OGG, WAV, M4A)
- 🔍 Búsqueda de álbumes por palabra clave
- 📊 Estadísticas en tiempo real (álbumes, artistas, años)
- 📄 Paginación para navegar por todos los resultados
- 📱 Diseño responsive (móvil, tablet, escritorio)
- 🎨 Estilo inspirado en Jamendo 2006 (azul/blanco)
